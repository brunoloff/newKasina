Welcome to newKasina

A quiet space for live biofeedback.

Make yourself at home

  1. Drag newKasina to the Applications folder in this disk image.
  2. Open your Applications folder and double-click newKasina.
  3. Allow Bluetooth access when macOS asks. Turn on your sensors; the Measurement service panel shows their connection status.

Everything runs inside the app. You do not need Terminal, Python, a separate service, or an account. Close the app to stop its measurement service.

A note about this preview

This is a development build. It has not been signed with an Apple Developer ID or notarized by Apple, so your Mac may block the first launch.

If you trust this copy from Bruno, first try opening it, then go to System Settings → Privacy & Security, scroll to the message about newKasina, choose Open Anyway, and confirm. You normally only need to do this once for this copy.

Apple's explanation of the first-open check

No sensor? You can still explore.

Open Settings and turn on simulated signals to try the displays. Simulation is labeled in the app so you can distinguish it from real measurements.

If a sensor does not appear

  • For Bluetooth sensors, check System Settings → Privacy & Security → Bluetooth → newKasina, then reopen the app. Close other apps using the sensor.
  • For ThoughtStream, plug in its USB cable and turn the unit on. The Measurement service panel lets you choose another serial port if automatic detection does not find it.
  • If ThoughtStream is missing from the connection list, our tested unit uses a Silicon Labs CP2102 USB adapter. Get the macOS CP210x VCP driver from Silicon Labs. Open its ZIP, open SiLabsUSBDriverDisk.dmg, and run the installer. Follow its prompts to allow the driver, then reconnect the USB cable and refresh the connection list in newKasina.

Requires macOS 13 Ventura or newer and a Metal-capable Mac. Download Apple Silicon for an M-series Mac or Intel for an Intel Mac; Apple menu → About This Mac shows which you have.
